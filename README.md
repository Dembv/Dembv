## Projets publics (6)

| Projet | Description | Technologies |
|--------|-------------|--------------|
| [**cryptoflow-data**](https://github.com/Dembv/cryptoflow-data) | Plateforme data de bout en bout pour le suivi du marché crypto : ingestion temps réel (trades Binance, OHLCV CoinGecko, transactions Etherscan) via Kafka, indicateurs Spark Structured Streaming (VWAP, RSI, Bollinger), stockage TimescaleDB, Redis et Delta Lake, transformations dbt, orchestration Airflow, API FastAPI avec WebSocket, dashboard Streamlit et alertes Slack / Telegram | Python, Kafka, Spark, TimescaleDB, Redis, dbt, Airflow, FastAPI, Streamlit, Docker |
| [**agroflow-data-platform**](https://github.com/Dembv/agroflow-data-platform) | Pipeline de données IoT de bout en bout : ingestion de capteurs agricoles et de données météo via Kafka, transformation Spark selon l'architecture Médaillon (Raw, Silver, Gold), entrepôt PostgreSQL en schéma en étoile, contrôle qualité, alertes agronomiques, orchestration Airflow et tableau de bord Metabase | Python, Kafka, Spark, Airflow, PostgreSQL, Metabase, Docker |
| [**ugb-inscription-administrative**](https://github.com/Dembv/ugb-inscription-administrative) | Application web de gestion des inscriptions administratives de l'UGB : espace scolarité (étudiants, formations, niveaux, années, annonces) et espace étudiant (inscription en ligne, certificat d'inscription en PDF) | Laravel, PHP, MySQL, Bootstrap |
| [**buur-events**](https://github.com/Dembv/buur-events) | Plateforme de publication et de réservation d'événements, avec notification par e-mail des inscrits. Architecture MVC écrite à la main (routeur, autoloader et middleware maison), sans framework | PHP, MySQL, Bootstrap |
| [**traduction_fr_en**](https://github.com/Dembv/traduction_fr_en) | Traduction automatique français vers anglais : modèle séquence-à-séquence à base de LSTM, évalué avec le score BLEU, et interface web « Tr'App » | Python, TensorFlow / Keras, Streamlit |
| [**DevOps-Projects**](https://github.com/Dembv/DevOps-Projects) | Fork d'un recueil de projets DevOps pour la pratique (CI/CD, conteneurs, cloud, infrastructure as code) | DevOps |
